1. SSH vào VPS

Thay YOUR_SERVER_IP bằng IP VPS thực tế.

ssh root@YOUR_SERVER_IP

apt update
apt upgrade -y

adduser deploy
usermod -aG sudo deploy

su - deploy

2. Cài Nginx

sudo apt install nginx -y

sudo systemctl enable nginx
sudo systemctl start nginx
sudo systemctl status nginx
Truy cập http://YOUR_SERVER_IP. Nếu thấy trang Welcome to nginx thì web server đã hoạt động.

4. Cài Composer và Git

sudo apt install git curl unzip -y

cd /tmp
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php

sudo mv composer.phar /usr/local/bin/composer

composer --version
git --version

5. Clone Laravel project

sudo mkdir -p /var/www/myapp
sudo chown -R deploy:deploy /var/www/myapp

cd /var/www

git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git myapp

cd /var/www/myapp

composer install \
  --no-dev \
  --prefer-dist \
  --optimize-autoloader \
  --no-interaction

Nếu project dùng Vite:

sudo apt install nodejs npm -y

npm ci
npm run build

6. Cấu hình Laravel .env

cp .env.example .env
nano .env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://api.example.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=myapp
DB_USERNAME=myapp
DB_PASSWORD=CHANGE_ME

CACHE_STORE=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
php artisan key:generate
Production tuyệt đối không nên để APP_DEBUG=true.

7. Cài và cấu hình MySQL

sudo apt install mysql-server -y
sudo mysql
CREATE DATABASE myapp
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

CREATE USER 'myapp'@'localhost'
IDENTIFIED BY 'CHANGE_ME_STRONG_PASSWORD';

GRANT ALL PRIVILEGES
ON myapp.*
TO 'myapp'@'localhost';

FLUSH PRIVILEGES;
EXIT;
php artisan migrate --force

8. Permission

sudo chown -R deploy:www-data /var/www/myapp

sudo find /var/www/myapp -type f -exec chmod 644 {} \;
sudo find /var/www/myapp -type d -exec chmod 755 {} \;

sudo chgrp -R www-data storage bootstrap/cache
sudo chmod -R ug+rwx storage bootstrap/cache
Không dùng chmod -R 777 cho toàn bộ project.

9. Configure Nginx cho Laravel

sudo nano /etc/nginx/sites-available/myapp
server {
    listen 80;
    listen [::]:80;

    server_name api.example.com;

    root /var/www/myapp/public;
    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ ^/index\.php(/|$) {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;

        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        fastcgi_param DOCUMENT_ROOT $realpath_root;

        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
sudo ln -s \
/etc/nginx/sites-available/myapp \
/etc/nginx/sites-enabled/myapp

sudo rm -f /etc/nginx/sites-enabled/default

sudo nginx -t
sudo systemctl reload nginx
Nginx root phải trỏ vào /var/www/myapp/public, không phải thư mục root của Laravel.

12. Queue Worker bằng Supervisor

sudo apt install supervisor -y

sudo nano /etc/supervisor/conf.d/myapp-worker.conf
[program:myapp-worker]
process_name=%(program_name)s_%(process_num)02d

command=php /var/www/myapp/artisan queue:work redis --sleep=3 --tries=3 --timeout=90

autostart=true
autorestart=true

user=www-data
numprocs=2

redirect_stderr=true
stdout_logfile=/var/www/myapp/storage/logs/worker.log

stopwaitsecs=3600
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start myapp-worker:*
sudo supervisorctl status

13. Laravel Scheduler

sudo crontab -u www-data -e
* * * * * cd /var/www/myapp && php artisan schedule:run >> /dev/null 2>&1

14. Deploy khi có code mới

cd /var/www/myapp

php artisan down || true

git pull origin main

composer install \
  --no-dev \
  --prefer-dist \
  --optimize-autoloader \
  --no-interaction

php artisan migrate --force

php artisan optimize:clear
php artisan optimize

php artisan queue:restart

php artisan up

Nếu frontend dùng Vite:

npm ci
npm run build

15. Production Checklist

  • APP_ENV=production
  • APP_DEBUG=false
  • Nginx root trỏ vào /public
  • HTTPS hoạt động
  • Không dùng MySQL root cho application
  • Không expose port 3306 và 6379 ra Internet
  • storage và bootstrap/cache có quyền ghi
  • Queue Worker chạy bằng Supervisor
  • Scheduler chạy bằng cron
  • .env không nằm trong Git
  • Có database backup
  • Có log monitoring
